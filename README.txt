LUMÉA WEBSITE DEMO

Open index.html with VS Code Live Server.

Included:
- Reference-image based cream/green aesthetic
- Responsive home page
- Product cards with images cropped from the supplied reference
- Search, filters and sorting
- Product quick view
- Add to bag / cart drawer / quantity controls
- Demo checkout and local order history
- Signup and login UI
- Admin dashboard with product adding, order stats and revenue
- About Us and Journal sections

IMPORTANT: This is a front-end demo. Authentication, payments, inventory, admin authorization and real order processing need a secure backend/database for production.
